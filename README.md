# Auto Libre

Sitio web de compra y venta de autos creado con HTML, CSS y JavaScript.

## Publicar en GitHub Pages

1. Subí todos estos archivos directamente a la raíz del repositorio.
2. Entrá en **Settings > Pages**.
3. Elegí **Deploy from a branch**.
4. Seleccioná `main` y `/(root)`.
5. Presioná **Save**.

El archivo principal es `index.html`.
